# Evidența produselor

Приложение учёта товара (румынский интерфейс) для iPhone, PWA. Данные хранятся в самом приложении на телефоне.

## Как выложить на GitHub Pages
1. Создайте репозиторий на github.com (например `produse`).
2. Загрузите в корень все файлы из архива.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/produse/`.

## Установка на iPhone
1. Откройте ссылку в **Safari**.
2. Нажмите «Поделиться» (квадрат со стрелкой) → «На экран «Домой»» → «Добавить».
3. Запускайте приложение с иконки на главном экране.

Важно: данные из Safari и данные установленного приложения хранятся отдельно, так что начинайте вводить товары уже после установки на главный экран.

## Обновление
После правки файлов измените `const C='produse-v2'` в `sw.js` (на `v3` и т.д.), чтобы телефон подтянул новую версию.
